Documentación

Todos los comandos, en un solo lugar.

Sintaxis, flags y ejemplos reales para cada comando de DataForge CLI.

Free

Comandos base

scan

dataforge scan [ruta]

Recorre recursivamente el proyecto, extrae el contexto de código y consulta al motor de IA activo para generar un reporte integral de arquitectura, riesgos y sugerencias. Se guarda en Markdown dentro de dataforge-reports/.

explain

dataforge explain [archivo]

Explica en detalle qué hace un archivo específico: propósito, estructura y decisiones de diseño probables.

map

dataforge map [ruta]

Genera un mapa ASCII de la arquitectura del repositorio: cómo se conectan los módulos entre sí.

ask

dataforge ask [ruta]

Abre un chat interactivo con el contexto completo del proyecto cargado. Escribe salir para terminar la sesión.

onboard

dataforge onboard [ruta]

Genera una guía de onboarding: resumen del proyecto, punto de entrada, archivos críticos y primeros pasos.

welcome

dataforge welcome

Abre la carta de bienvenida de DataForge CLI en el navegador.

setup

dataforge setup

Asistente interactivo para configurar o reconfigurar tu instalación: proveedor de IA, API key, idioma (es/en) y tema visual.

  • Free — proveedor fijo en Groq + idioma + tema por defecto
  • Pro — desbloquea los temas: Dark, Light, Tokyo Night, Dracula
  • Teams — desbloquea selector de proveedor: OpenAI, Gemini, Claude, Ollama

Si no hay licencia activa para una opción, setup la oculta en vez de mostrarla deshabilitada — nunca regala funciones de pago.

Pro

Comandos avanzados

doc++

dataforge doc++ [ruta]

Genera documentación de nivel producción: README, DOCUMENTATION.md, guía técnica, instalación, arquitectura y dependencias.

architecture++

dataforge architecture++ [ruta]

Genera diagramas Mermaid completos de relaciones entre carpetas, dependencias y flujo interno del proyecto.

explain (audiencia)

dataforge explain [archivo] --junior
  • --junior — explicación paso a paso, sin dar nada por sabido
  • --senior — directo al punto, enfocado en decisiones de diseño
  • --teacher — pensado para enseñar el concepto, no solo el código
  • --manager — enfocado en impacto y riesgo, sin jerga técnica

export++

dataforge export [ruta] --md
  • --md — Markdown
  • --txt — texto plano
  • --json — estructurado, para integrarlo a otra herramienta
  • --html — listo para compartir en el navegador

preset

dataforge preset onboarding

Ejecuta automáticamente Scan → Explain → Map → Documentation++ → Architecture++ → Export, en un solo paso.

license

dataforge license DFORGE-PRO-XXXX-XXXXX

Activa tu licencia PRO o Teams localmente. Usa dataforge license status para ver el plan y vencimiento actuales.

Teams

Configuración de equipo

Team Branding

Personaliza la firma que aparece en toda la documentación generada, para que salga con la identidad de tu estudio o cliente en vez de la de DataForge.

Enterprise AI — multi-proveedor

Cada integrante del equipo puede usar su propia API key. El enrutamiento ya está implementado en el CLI; dataforge setup lo desbloquea solo con licencia Teams activa.

  • Groq — velocidad pura para scan y ask
  • Claude — prosa técnica y arquitectura elegante
  • OpenAI — precisión lógica estricta
  • Gemini — análisis masivo de contexto
  • Ollama — motor local, 100% offline

Team Presets

El administrador del equipo define presets compartidos (por ejemplo: Architecture → Documentation → Export HTML) para que todos sigan el mismo flujo.

Shared Configuration

Temas, prompts y presets se comparten entre todo el equipo para mantener consistencia en la documentación de todos los proyectos.
