Instalación

Corriendo en menos de un minuto.

Sin cuentas, sin paywall. Clona, instala y corre tu primer scan.

Requisitos

  • Python 3.9+ instalado y en el PATH
  • pip para instalar dependencias
  • git (opcional si descargas el ZIP)
  • Una API key de Groq — gratuita en console.groq.com

Sistemas soportados

  • 🪟 Windows 10 / 11
  • 🍎 macOS 12+
  • 🐧 Linux (cualquier distro con Python 3.9+)
Teams

Aviso sobre proveedores de IA

Con licencia Teams activa, dataforge setup te deja elegir motor de IA. Ollama corre 100% local y offline — sin API key y sin enviar tus datos a nadie, solo necesitas tenerlo corriendo (ollama serve) antes de seleccionarlo. Groq, OpenAI, Gemini y Claude sí requieren su propia API key de cada proveedor.

dataforge setup
⚙️ [DataForge CLI] Configuración Inicial del Sistema
🤖 Selecciona tu motor de IA Enterprise:
  [1] groq   -> Ultra rápido (requiere API key)
  [2] openai -> Máxima precisión lógica (requiere API key)
  [3] gemini -> Análisis masivo y contexto global (requiere API key)
  [4] claude -> Prosa técnica de nivel producción (requiere API key)
  [5] ollama -> Ejecución local y offline (sin API key — requiere `ollama serve`)
Elige proveedor [1-5 o nombre] (default: groq):

En el plan Free, setup queda fijo en Groq — este selector solo aparece con licencia Teams activa. Ver planes.

Elige tu método

Todos terminan en el mismo lugar: un main.py listo para correr.

python -c "import urllib.request; exec(urllib.request.urlopen('https://raw.githubusercontent.com/RabbitGamesDev/DataForge-CLI/main/install.py').read())"

Funciona igual en PowerShell, CMD, Bash y Zsh — Python hace todo el trabajo, no depende de tuberías de shell. Descarga el ZIP, lo descomprime en ./dataforge-cli e instala las dependencias con pip automáticamente.

git clone https://github.com/RabbitGamesDev/DataForge-CLI.git cd DataForge-CLI pip install -r requirements.txt

Para quien prefiere ver el código antes de correr nada, o instalar todo a mano.

Descargar DataForge-CLI-main.zip
  1. Descomprime el ZIP en la carpeta que prefieras.
  2. Entra a la carpeta descomprimida: cd DataForge-CLI-main
  3. Instala las dependencias:
pip install -r requirements.txt

Quick start

Cuatro pasos, de cero a tu primer reporte.

1

Configura tu API key de Groq

DataForge te la pedirá la primera vez que lo ejecutes y la guarda localmente.

2

Corre tu primer scan

Apunta a cualquier carpeta de proyecto y deja que DataForge la recorra completa.

3

Explora los demás comandos

explain para un archivo puntual, map para ver toda la arquitectura de un vistazo.

4

(Opcional) Activa PRO

Si ya tienes una licencia, actívala directamente desde la terminal con un solo comando.

~/DataForge-CLI
$ python main.py
🔑 Ingresa tu API key de Groq: ****************
✅ Configuración guardada correctamente.
$ python main.py scan ./mi-proyecto
🔍 Escaneando: mi-proyecto...
✅ Reporte guardado en ./report.md
$ python main.py explain ./mi-proyecto/main.py
🤖 Generando explicación...
$ python main.py license DFORGE-PRO-XXXXX-XXXXX
✅ Licencia PRO activada correctamente.
$
