Features

Un comando para cada etapa de tu proyecto.

Desde un escaneo rápido hasta documentación de nivel producción, sin salir de la terminal.

🟢 Free

Para estudiantes, hobbyists y probar la herramienta

$0 USD

scan

dataforge scan .

Analiza un proyecto completo y genera un reporte básico.

explain

dataforge explain archivo.py

Explica en detalle qué hace un archivo específico.

map

dataforge map .

Genera un mapa ASCII de la arquitectura del proyecto.

ask

dataforge ask .

Chat interactivo con IA sobre tu código.

onboard

dataforge onboard .

Genera documentación básica de bienvenida para nuevos devs.

welcome

dataforge welcome

Abre la carta de bienvenida de DataForge CLI.

setup

dataforge setup

Configura proveedor de IA, idioma y tema. En Free queda fijo en Groq — Pro y Teams desbloquean el resto.

Incluye

  • Interactive Setup
  • Local-first
  • Groq API
  • Basic Reports
  • Basic Architecture
  • Firma automática en reportes

Generated by [tu proyecto] · Powered by DataForge CLI by RGS Labs™

🔵 Pro

Para freelancers, desarrolladores y pequeños estudios

$15 USD/mes

Incluye todo lo de Free, más:

PRO

doc++

dataforge doc++ .

Genera documentación de nivel producción: README profesional, DOCUMENTATION.md, guía técnica, instalación, arquitectura, dependencias, flujo del proyecto y organización del código. Mucho más detallado que Free.

PRO

architecture++

dataforge architecture++ .

Diagramas Mermaid completos: relaciones entre carpetas, dependencias, flujo interno, módulos, componentes y explicación de IA de toda la arquitectura.

PRO

explain like

dataforge explain auth.py --junior

La explicación cambia según la audiencia: --junior, --senior, --teacher o --manager.

PRO

export++

dataforge export . --md

Exporta cualquier reporte generado a --md, --txt, --json o --html.

PRO

presets

dataforge preset onboarding

Ejecuta automáticamente Scan → Explain → Map → Documentation++ → Architecture++ → Export, con un solo comando.

PRO

themes & branding

Temas Dark, Light, Tokyo Night y Dracula. Sin firma de DataForge en los reportes: todo queda limpio con tu propia marca.

También incluye

  • Early access a funciones nuevas
  • Sin firma / branding limpio
  • Activación con dataforge license
🟣 Teams

Para estudios, startups y equipos

$39 USD/5 usuarios/mes

Incluye todo lo de Pro, más:

TEAMS

Team Branding

Toda la documentación sale con la identidad del cliente. Por ejemplo: Generated by Solar Flare Productions — sin mencionar DataForge.

TEAMS

Enterprise AI

Compatible con Groq, OpenAI, Gemini, Claude y Ollama — el enrutamiento ya está en el CLI. Cada desarrollador usa su propia API key; dataforge setup lo desbloquea con licencia Teams activa.

TEAMS

Team Presets

Los administradores crean presets para todo el equipo: Architecture → Documentation → Export HTML → Export Markdown → Save. Todos usan exactamente el mismo flujo.

TEAMS

Shared Configuration

El equipo comparte configuración, temas, prompts y presets para mantener la documentación consistente entre todos los proyectos.

TEAMS

Priority Updates & activación automática

Todas las funciones nuevas llegan primero a Teams. La activación con dataforge license XXXXX-XXXXX detecta automáticamente que se trata de un plan Teams.
