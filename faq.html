FAQ

Preguntas frecuentes

Todo lo que necesitas saber sobre licencias, privacidad y cómo funciona DataForge por dentro.

Licenciamiento

Sí. El núcleo de DataForge CLI (scan, explain, map, ask, onboard, setup) está publicado bajo licencia Apache 2.0 en GitHub y seguirá siendo así. PRO y Teams son un modelo Open-Core: funciones adicionales sobre el mismo núcleo abierto, no un fork cerrado.

Después de tu compra recibes un código con el formato DFORGE-PRO-XXXX-XXXXX por correo. Lo activas con python main.py license TU-CODIGO y el CLI lo guarda localmente en ~/.dataforge/license.json.

El plan PRO está pensado para una persona. Si necesitas licencias para varios equipos de tu computadora personal o para tu equipo de trabajo, Teams está diseñado exactamente para eso, con administración centralizada.

Privacidad y Groq

No. DataForge es local-first: el escaneo y la lectura de archivos ocurren en tu máquina. El único tráfico de red es la consulta a la API de Groq para generar el análisis, usando la API key que tú mismo configuras.

Groq es el proveedor de inferencia de IA que usamos por su velocidad de respuesta, ideal para un flujo de terminal donde no quieres esperar. Tú traes tu propia API key; DataForge no la comparte con nadie más.

No. Los reportes se guardan como archivos Markdown directamente en tu proyecto local. RGS Labs no tiene acceso a ellos.

Planes y actualizaciones

Sí, sin permanencia. Al cancelar, tu licencia sigue activa hasta el final del periodo ya pagado y luego el CLI vuelve automáticamente a las funciones de Free.

El núcleo recibe mejoras continuas en GitHub. Las versiones con features PRO nuevas se anuncian en el repositorio y en esta misma web, sin necesidad de que reinstales nada manualmente salvo un git pull.

Está en el roadmap. La idea es que puedas elegir tu proveedor preferido (Groq, OpenAI, Anthropic, modelos locales) sin cambiar tu flujo de trabajo.
